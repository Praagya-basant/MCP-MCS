# BASANT SSM

Signed Sample Management — Module 1 (MCS) of the BASANT platform.

## Quick start

```
cp .env.example .env   # fill in VITE_SUPABASE_URL / VITE_SUPABASE_ANON_KEY
npm install
npm run dev
```

See [CLAUDE.md](./CLAUDE.md) for full architecture notes and the complete
Supabase setup checklist (schema, edge functions, first admin user).
